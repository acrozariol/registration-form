# Estrelas do Amanhã - Enrollment Form

A responsive enrollment form, designed to collect children's registration information through a clean and user-friendly interface.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Features

- Responsive two-column layout
- Child, guardian, and address information sections
- File upload for birth certificate
- Radio buttons, checkboxes, and form validation
- Accessible and organized form structure
- Modern UI with custom styling
